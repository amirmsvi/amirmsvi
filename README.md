# 💫 About Me
I am an **AI & Full-Stack Systems Engineer** passionate about bridging the gap between intelligent models, silicon, and scalable user interfaces. My expertise spans the entire AI lifecycle—from optimizing C++ inference on edge devices to orchestrating LLM workflows, vector databases, and full-stack web architectures using Python, TypeScript, and React. 

I specialize in end-to-end AI engineering: turning raw data and machine learning models into reliable, low-latency products across both embedded hardware and cloud environments. Currently, I’m architecting three personal projects focused on Edge AI, intelligent agent workflows, and real-time data pipelines.
